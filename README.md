## Usage
```bat
usage: Image2Ascii.py [-h] [-o OUTPUT] [-x WIDTH | -y HEIGHT] imageName

positional arguments:
  imageName

options:
  -h, --help            show this help message and exit
  -o, --output OUTPUT   sets the output directory
  -x, --width WIDTH     sets the width
  -y, --height HEIGHT   sets the height
```
